# TabIt

A Chrome extension that automatically closes the oldest tab when the number of open tabs exceeds a user-defined limit.

## Features
- Set a maximum tab limit via options.
- Automatically manages tab clutter by closing the least recently used tab.
- Lightweight and efficient.

## Installation
1. Clone this repository.
2. Go to `chrome://extensions/` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the extension folder.
